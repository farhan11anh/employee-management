# 🧑‍💼 Employee Management App - Angular

Aplikasi manajemen karyawan berbasis **Angular** dengan tampilan modern menggunakan **Angular Material**, **NG-ZORRO**, dan notifikasi dari **ngx-toastr**.

## ✨ Fitur

* ✅ Login dengan hardcoded credentials
* ✅ Filter, search, sorting, dan pagination
* ✅ CRUD (tambah, edit, hapus) data karyawan
* ✅ Format data seperti tanggal dan gaji (IDR)
* ✅ Penyimpanan data **persisten** di **LocalStorage** (tidak hilang walau page di-refresh)
* ✅ Responsif & bisa horizontal scroll di mobile
* ✅ Query params tersimpan di URL

## 📆 Instalasi

```bash
git clone https://github.com/username/employee-management-angular.git
cd employee-management-angular
npm install
ng serve
```

## 📁 Penyimpanan Data

Data karyawan akan **disimpan secara otomatis ke Local Storage**. Selama browser tidak menghapus data lokal, perubahan akan tetap tersimpan meskipun aplikasi ditutup atau halaman di-refresh.
